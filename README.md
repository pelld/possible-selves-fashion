# Possible Selves — fashion interface prototype

A first working prototype of a fictional premium fashion shop.

## What it tests

1. Four faint outline figures appear before any products.
2. The body is the navigation.
3. Selecting a body area creates two distinct possible selves.
4. The customer clicks the self that should be sent back.
5. The survivor becomes the new present.
6. After several choices, the studio begins taking a position.
7. Optional Studio Notes influence colour, adventurousness, cost, materials and environmental priority.
8. Outfit colour gradually and subtly enters the previously white interface.
9. Price is available on hover, after style has been encountered first.

## Deliberate limitation

The garments are detailed visual placeholders, not product photographs. The first prototype is testing the interaction, pacing and visual hierarchy. A real version would replace each garment layer with photographed product cut-outs prepared to fit the neutral figure.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

For the GitHub account `pelld`:

1. Create a repository such as `possible-selves-fashion`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Publish from the `main` branch and `/ (root)` folder.
5. The site will be available at `https://pelld.github.io/possible-selves-fashion/`.

The code is wide-formatted and divided into numbered, commented sections for incremental editing.
